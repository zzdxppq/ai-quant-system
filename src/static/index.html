次日卖出规则

9:27 邮件推送后按昨日形态 + 今日竞价% 生成表内「卖出建议」行（与 next_day_sell_advice 同源）。

全局

  • 硬止损：今日竞价 ≤ −2.5% 或 ≥ +9% → 开盘卖出
  • 全市场竞价跌停 ≥ 10 家 → 竞价卖出（不论形态）
  • 1进2 < 10%：盈利单 部分止盈减半；亏损单 立卖

昨涨停

  • 今一字（竞价 ≥ 9.8%）→ 继续持有
  • 竞价 3%~7% → 持有，回落 3% 止盈
  • 竞价 > 7% → 部分止盈（卖一半）
  • 竞价偏弱 → 观察 5 分钟，不翻红则卖

昨炸板

  • 今竞价跌停 → 挂跌停卖出
  • 昨换手 > 20% → 竞价卖出
  • 其余 → 开盘卖出（炸板低开概率高）

昨收正 / 昨收负

  • 昨收正：高开 ≥ 2% 观察；平开区 5 分钟不翻红则卖；低开直接卖
  • 昨收负：竞价 ≥ +1% 弱转强观察；否则开盘卖

色标：卖出建议为绿、持有为红、部分止盈为黄（A 股涨跌色惯例）。

个股决策评分规则（v4.0）

列表「决策」列与 9:27 per_stock_decision 同源（回测校准 v4.0）。

核心原则

  • 1进2主流程不做；零命中时可公式兜底（仅 1 只）
  • 2进3：重点/正常 → 3层=30%；轻仓试错/边缘票 → 2层=20%
  • 3进4 / 4进5+ 基础 3层=30%，可升 4层=40%
  • 12%~15% 晋级率为最佳窗口

4进5+（全满足）30%（3层）可升 4 层；晋级率<8% 不做

2进3 硬门槛 → 分位仓位

  • 硬门槛：竞价 4.0%~7.5%；换手 ≥0.3%；昨换手 ≥3%；额比 ≥0.74；晋级率 ≥8%
  • 额比 0.74~0.8（差≤0.06）→ 仅可作 边缘票 2层；≥0.8 才可升正常/重点
  • 高标绿盘且晋级率 <12% → 0层；一字板豁免昨换手/额比
  • 3层（30%）：重点参与 / 正常参与
  • 2层（20%）：轻仓试错 / 边缘票
  • 邮件：多票只推可开仓；仅 1 只时即使条件未达也推送并标轻仓试错 2层
  • 主选股 0 命中 → 跑 1进2 公式，有且仅有 1 只才落库推送（轻仓试错 2层）
  • 口诀：4~7.5看竞价，换手0.3打底；晋级12~15加高标红盘→重点 3层

3进4（须全满足）

  • 晋级率 ≥10%；竞价涨幅 ≥5.0%（6~7.5% 优先）
  • 集中度 ≥25% 或 概念 ≥2；换手 >0.5%；空间板不跌停

4进5+（须全满足）

  • 晋级率 ≥8%；竞价 4.0%~7.5%
  • 集中度 ≥25% 或 概念 ≥2；换手 >0.5%
  • 5板+ 且竞价 >6% 不做

全局：跌停潮≥9 仓位减半（15→7.5%、30→15%、40→20%）；晋级率>25% 仓位×0.7。 改规则后请 POST /api/recompute-screener-decisions 重算决策列。

各指标定义与计算

参与决策指标（按决策树顺序）

  • 竞价跌停（主板）(>5⚠) / 跌>9% (>9⚠)
    定义：左为主板（60/00 非 ST）在跌停样本中、竞价跌幅 ≤ −9.9% 的只数；右为全市场跌幅 >9%的个股家数（与情绪面「市场风向」同源）。
    公式：计数，无加权。谨慎触发：左 >5 或 右 >9。
  • 加权接力情绪指数
    定义：昨日东财涨停池内全部主板非 ST 标的，在行情中有今开/昨收的样本。
    公式：单只竞价溢价 Pᵢ = (今开ᵢ ÷ 昨收ᵢ − 1) × 100%；按东财 lbc 分三档取算术平均 A₁,A₂,A₃（首板档含 lbc≤1，含接口缺省 0）；指数 I = 0.2×A₁ + 0.5×A₂ + 0.3×A₃（%）。≤0% 触发空仓。
  • 关于 lbc=0：见东财字段说明；与首板档合并，不丢弃样本。
  • 1进2成功率
    定义：上一交易日盘后复盘 scorecard「1进2成功率」（与 9:27 选股环境口径一致，非当日 latest_review）。≥15% 视为偏强。
  • 昨日连板高标竞价
    定义：取 latest_leader.main_board_leaders 中昨日主板最高连板档（≥2 板）：同档多只取竞价涨跌幅算术平均（展示如「4只3板」）；仅一只则取该股。若无主板连板高标样本，则回退 market_leader（10 日市场高标）。
    公式：(今开 ÷ 昨收 − 1) × 100%，与选股引擎里 evaluate_lianban_leader / 市场高标反馈同源字段。

参考指标（不直接参与决策树）

  • 昨日跌停平均反馈、昨日炸板平均反馈
    公式：各池命中样本的今日竞价涨幅简单算术平均（%），详见 latest_leader 中对应统计块。
  • 梯队加权竞价(10日)
    公式：对 10 日榜 TOP30 代码按名次赋权 wᵢ=(N−rankᵢ)/N，W = Σ(wᵢ·Pᵢ) / Σwᵢ，其中 Pᵢ 同上；与 latest_sentiment.weighted_auction_gain 同源。

三、决策结论：满足「主板竞价跌停 (>5⚠) 或 跌>9% (>9⚠)」进入谨慎（若同时加权接力 ≤0% 则空仓）；否则接力 ≤0% 空仓；否则按 1 进 2 与昨日连板高标是否红盘映射仓位层数。
